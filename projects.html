02 / Applied machine learning

Instituto de Estudios Cajasol

Master's project · 2026

ATP tennis analytics & AI

A project spanning data engineering, predictive modelling and interactive exploration of professional tennis.

Data and prediction

I engineered 86 features from more than 28,000 ATP matches, using prior-match information such as surface-specific Elo and recent performance statistics. I built Python ETL pipelines and relational data models, then trained XGBoost models for prediction.

I compared tournament predictions with Elo baselines, examining probability calibration, performance by round and limitations for players with sparse match histories.

Exploration and interaction

I explored player profiles through PCA and k-means clustering, created a six-page Power BI dashboard, and developed an AI assistant with 13 MCP tools for data exploration and access to model predictions.

  • Python
  • XGBoost
  • Power BI
  • MCP

05 / Formal verification

University of Warwick

MA4N1 · Group project

Cauchy's theorem in Lean

A collaborative formal proof of Cauchy's theorem on a triangle using Goursat's method, built in Lean 4 on top of Mathlib.

The project develops definitions of paths, path integrals and triangles, alongside a fundamental theorem of calculus for complex path integrals. I contributed as part of the group; the repository contains the team's implementation.

  • Lean 4
  • Mathlib
